Mask

Reversible Pattern

Replaces sensitive values with redacted patterns. Preserves file structure and format.

Hash

One-Way

Irreversibly transforms sensitive values using a cryptographic hash. Cannot be undone.

SHA-256 · SHA3-256 · BLAKE3

AES-256-GCM

Securely encrypts the file with a password. Restore the original file later with the same password.
